# Red Pitaya Self-Excited Loop (SEL) LLRF Control System

## Project Overview
This repository contains a complete FPGA-based **Self-Excited Loop (SEL)** Low-Level Radio Frequency (LLRF) control system developed for the **Red Pitaya STEMlab 125-14 Pro**. 

The project demonstrates an end-to-end model-based design pipeline—from high-level DSP modeling in Simulink to automatic VHDL generation via MATLAB HDL Coder, Vivado hardware implementation, and high-level control via Jupyter Notebooks.

*Developed as part of my engineering internship to demonstrate low-cost, real-time RF control capabilities.*

---

## System Architecture & Stack

* **Hardware Target:** Red Pitaya STEMlab 125-14 Pro (Xilinx Zynq-7010 FPGA, $f_{clk} = 125\text{ MHz}$)
* **DSP & Control Design:** MATLAB / Simulink
* **IP Generation:** MATLAB HDL Coder
* **Synthesis & Implementation:** Xilinx Vivado (TCL build scripts included)
* **High-Level Control & Verification:** Python / Jupyter Interface

## How to Rebuild the Project

### 1. Vivado Block Design & Bitstream Generation
To recreate the hardware project from scratch without manually configuring Vivado:
1. Launch Xilinx Vivado.
2. Open the TCL Console and navigate to this repository directory.
3. Run the automated build script:
   ```tcl
   source Sources/Vivado/build.tcl
   ```

### 2. Loading to Red Pitaya
Run `program_fpga.tcl` or upload the compiled `.bit` bitstream file directly to the board to interact with the registers via the Jupyter Notebook interface.

## Design Rules & Engineering Workflow

<details>
<summary><b>1. Simulink Modeling & HDL Coder Compliance Rules</b></summary>

To ensure synthesized VHDL matches real-time constraints ($T_s = 8\text{ ns}$):
* **Solver & Timing:** Global solver set to discrete execution inside the DUT subsystem ($f_{clk} = 125\text{ MHz}$). Continuous-to-discrete boundaries use `Rate Transition` blocks.
* **Fixed-Point Datatypes:** ADC inputs map to 14-bit signed/unsigned formats; DSP math uses 18-bit and 25-bit word lengths to match native Xilinx Zynq DSP48E1 slice multipliers ($25 \times 18$).
* **Feedback Loops:** Every feedback path contains explicit delay registers (`Unit Delay`) to eliminate algebraic loops and ensure deterministic timing.
* **Synthesis Constraints:** Restricted to blocks available via MATLAB `hdllib`.
</details>

<details>
<summary><b>2. HDL Workflow Advisor Setup</b></summary>

* **Target Device:** Generic Xilinx Zynq Board (`xc7z010-clg400-1`).
* **Interface Mapping:** * High-speed `ADC_I/Q` and `DAC_I/Q` mapped to external platform ports.
  * Control registers (`Phase_Offset`, `Gain`) mapped to the `AXI4-Lite` bus.
* **Optimizations Enabled:** Adaptive pipelining, delay balancing, and distributed pipelining for critical path reduction.
</details>

<details>
<summary><b>3. Timing Closure Strategy (125 MHz)</b></summary>

* Operating within an **8 ns clock period** constraint on Zynq-7010 fabric.
* Worst Setup Slack (WSS) and Worst Hold Slack (WHS) monitored via Vivado Timing Summary reports.
* Timing violations resolved by adding pipeline registers between heavy combinatorial paths and leveraging distributed pipelining in HDL Coder.
</details>
